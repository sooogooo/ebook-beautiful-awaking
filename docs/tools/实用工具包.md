### 2. 医美准备度评估量表（Medical Aesthetic Readiness Scale, MARS）

**目的**：评估个体进行医美的心理准备程度

#### A. 动机评估（每项1-5分）
- [ ] 我清楚自己想做医美的真实原因
- [ ] 我的动机主要来自内在，而非外在压力
- [ ] 我对医美的效果有合理的期望
- [ ] 我已经考虑过其他非医美的解决方案

#### B. 知识评估（每项1-5分）
- [ ] 我了解目标项目的基本原理和风险
- [ ] 我知道如何选择合格的医生和机构
- [ ] 我了解项目的恢复期和注意事项
- [ ] 我知道可能的并发症和处理方法

#### C. 心理评估（每项1-5分）
- [ ] 我能够承受项目带来的不适和疼痛
- [ ] 我对可能的不完美结果有心理准备
- [ ] 我的家人和朋友支持我的决定
- [ ] 我有足够的经济能力承担费用

**准备度判断**：
- 40-50分：准备充分，可以考虑进行
- 30-39分：基本准备，建议进一步完善
- 20-29分：准备不足，需要更多时间考虑
- 20分以下：暂不建议进行医美

## 📝 实践练习工具

### 1. 美感日记（Beauty Journal）

**模板**：

```
日期：____年__月__日

今日美感观察：
今天我注意到哪些美好的事物？（颜色、形状、光影、质感等）

美丽感受记录：
这些美好事物带给我什么样的感受？（平静、愉悦、兴奋等）

自我关怀行动：
今天我为自己的美丽做了什么？（护肤、运动、正念冥想等）

积极反思：
今天我有什么新的发现或感悟？
```

**使用指南**：连续记录21天，培养审美觉察力和积极情绪。

### 2. 美丽目标设定表（Beauty Goal Setting Worksheet）

**SMART目标模板**：

| 目标要素 | 具体描述 |
|----------|----------|
| **S** - 具体的（Specific） | 我想要达成的具体美丽目标是什么？ |
| **M** - 可衡量的（Measurable） | 如何衡量目标的达成程度？ |
| **A** - 可实现的（Achievable） | 这个目标现实吗？需要什么资源？ |
| **R** - 相关的（Relevant） | 这个目标与我的价值观相关吗？ |
| **T** - 有时限的（Time-bound） | 计划在什么时间前达成？ |

**示例**：
- **具体**：改善皮肤暗沉，让肤色更均匀
- **可衡量**：色斑减少50%，肤色提亮2个色号
- **可实现**：通过规律护肤、健康饮食和充足睡眠
- **相关**：希望看起来更有精神，提升自信心
- **时限**：6个月内看到明显改善

### 3. 铁三角沟通练习（Triangle Communication Exercise）

**与医生/咨询师沟通模板**：

```
沟通前准备：
1. 我的主要困扰：__________________
2. 我的期望效果：__________________
3. 我的预算范围：__________________
4. 我的担心事项：__________________

沟通中要点：
□ 清晰表达需求
□ 询问具体方案
□ 了解风险副作用
□ 询问恢复时间
□ 确认总费用

沟通后总结：
医生建议方案：__________________
我的理解：______________________
还需要了解的信息：______________
```

**沟通技巧提示**：
- 使用"我感觉..."的句式表达感受
- 准备具体问题而非模糊描述
- 要求医生用通俗易懂的语言解释
- 不要害怕询问风险和副作用
- 可以录音或做笔记

### 4. 社会比较觉察练习（Social Comparison Awareness Exercise）

**每日觉察记录**：

```
时间：______

触发事件：
我在什么情况下与他人进行了外貌比较？

比较内容：
我比较了哪些方面？具体是什么？

情绪反应：
比较后我有什么感受？（焦虑、自卑、嫉妒等）

理性分析：
这个比较公平吗？我看到的是真实的对方吗？

积极重构：
我如何用积极的角度看待这个情况？
我可以从中学习到什么？
```

**使用频率**：每当发现自己在进行社会比较时进行记录。

## 🎯 情绪管理工具

### 1. 美丽焦虑正念练习（Mindfulness Exercise for Beauty Anxiety）

**5分钟正念引导**：

1. **准备阶段**（1分钟）
   - 找一个安静的地方坐下
   - 轻轻闭上眼睛，深呼吸三次
   - 感受身体的重量和接触点

2. **觉察阶段**（2分钟）
   - 觉察当前关于外貌的焦虑想法
   - 不评判，只是观察这些想法的来去
   - 注意这些想法带来的身体感受

3. **接纳阶段**（1分钟）
   - 对自己说："我有这些想法是正常的"
   - 承认焦虑的存在，但不被它控制
   - 感受呼吸带来的平静

4. **重构阶段**（1分钟）
   - 想象自己用善意和智慧对待这些焦虑
   - 将注意力转移到身体的积极感受上
   - 设定一个积极的行动意图
