# 美的觉醒 - 积极心理学视角下的现代女性成长指南

> 一本整合美容心理学与积极心理学的完整著作，为现代女性和专业美容咨询师提供科学指导

## 📖 项目简介

本项目是一本完整的中文美容心理学著作，从积极心理学视角探讨现代女性的美丽认知与个人成长。全书共4个部分13个章节，将进化心理学、认知心理学与社会心理学融合，为读者提供理论与实践相结合的美丽成长方案。

## 📚 内容结构

### 第一部分：美的心理学
- **第1章** - 美丽的进化心理学基础
- **第2章** - 自我概念与镜像理论  
- **第3章** - 消费心理学的积极诠释

### 第二部分：理性的美丽
- **第4章** - 美丽的科学基础
- **第5章** - 积极决策理论框架
- **第6章** - 个性化美学与独特性

### 第三部分：实践的智慧
- **第7章** - 安全美容实践入门指南
- **第8章** - 美容咨询师专业发展
- **第9章** - 高级策略与特殊情境
- **第10章** - 职业道德与持续学习

### 第四部分：美的升华
- **第11章** - 内在美与魅力建设
- **第12章** - 社会价值与集体影响
- **第13章** - 技术时代的美丽未来

## ✨ 核心理念

本书倡导\"第三条道路\"的美学观：
- 拒绝消费主义过度包装与禁欲主义拒绝美丽的双重陷阱
- 整合外在形象与内在心理福祉
- 赋能个体做出自主、明智的选择
- 将美丽视为个人成长路径而非焦虑来源

## 🚀 快速开始

### 本地阅读

1. **克隆仓库**
   ```bash
   git clone https://github.com/sooogooo/ebook-beautiful-awaking.git
   cd ebook-beautiful-awaking
   ```

2. **直接阅读**
   - 打开 `medibeauconsultant.md` 阅读完整书稿
   - 或浏览 `docs/` 目录中的分章节内容

### 在线文档

1. **安装依赖**
   ```bash
   # 创建虚拟环境（推荐）
   python -m venv mkdocs-env
   source mkdocs-env/bin/activate  # Linux/Mac
   # 或 mkdocs-env\Scripts\activate  # Windows
   
   # 安装MkDocs及依赖
   pip install -r requirements.txt
   ```

2. **启动本地服务器**
   ```bash
   mkdocs serve
   ```
   访问 http://127.0.0.1:8000 查看在线文档

3. **构建静态站点**
   ```bash
   mkdocs build
   ```
   生成的静态文件将位于 `site/` 目录
